# 毕业设计实验补全方案

本文档规定算法实验中心中“待补实验”的数据采集与计算口径。未完成的实验保持
`pending`，不得用演示数据或手工编造的百分比替代。

## 1. 多人并发时延

- 人数：1、2、4、6 人；
- 每档至少 3 段视频，每段 30 秒；
- 分辨率和采样间隔保持一致；
- 记录检测人数、成功身份数、平均时延、P50、P95、漏检率；
- 同一视频分别运行 3 次，模型预热后开始统计。

结论应回答：人数增加后是否仍满足端到端 P95 小于 200ms，以及是否出现已注册
人员被陌生人阻塞的情况。

## 2. 活体攻击评估

- 真人样本、打印照片、手机静态照片、手机视频重放分别采集；
- 每类至少 30 次独立尝试；
- 记录真人通过/拒绝、攻击通过/阻断与是否触发随机动作；
- 计算 APCER、BPCER 与 ACER：
  - APCER = 被错误放行的攻击次数 / 攻击总次数；
  - BPCER = 被错误拒绝的真人次数 / 真人总次数；
  - ACER = (APCER + BPCER) / 2。

## 3. 时序特征融合消融

对同一组视频分别运行：

1. 单帧 SFace；
2. 多帧投票但不融合特征；
3. 质量加权时序特征融合（完整系统）。

比较每条轨迹的相似度标准差、身份抖动次数、最终识别率和平均确认帧数。只有使用
完全相同的视频输入，消融结论才具有可比性。

## 4. 阈值扩充

当前 SFace 基线仅包含 1 个注册身份。正式论文建议扩充到至少 10 个身份，每个身份
至少 5 张不同光照、角度和距离照片，并保留独立陌生人集。重新运行：

```powershell
python scripts\evaluate_sface.py
```

算法实验中心会自动读取新的 JSON 结果，不需要修改页面代码。
